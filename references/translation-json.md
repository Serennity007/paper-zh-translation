# 译文 JSON 格式（`zh_pageNN.json`）

每页一个文件，键是 `segments.json` 里的段落 id，值是中文文本。文件名决定加载顺序，用 `zh_page00.json`、`zh_page01.json`… 与页码对齐（页码从 0 开始）。

## 基本写法

```json
{
  "p3b36": "**模型层。**我们提取了采样数据集中全部 900 个模型的层信息……",
  "p3b37": "**表 3：**模型层数据类型分布。Others 包括 float64、uint8 和 int64。"
}
```

- `**…**` = 该片段加粗。只给真正的粗体片段加（图注的"图 3："、"表 3："、小节引导词如"**模型层。**"、原文的 run-in 标题），不要整段加粗。
- 段落内部的换行用 `\n` 表示（原文一个块里含多个自然段时），例如 `"……结论。\n**模型参数。**随后我们分析……"`。
- 项目符号要点直接写 `"• "` 开头，续行缩进由排版引擎自动处理；一个块里有多个要点时用 `\n• ` 分隔。

## 空字符串 = 只擦不写

```json
"p7b29": ""
```

该块会被擦除英文但不写中文。用于被公式/徽标切碎的碎片块——整句译文写在相邻的主块里，并用 `merge` 把它们的排版框合并。

## `@id` 排版元数据

| 键 | 作用 | 例子 |
|---|---|---|
| `align` | 居中（论文标题） | `{"align": "center"}` |
| `bold` | 强制整块加粗 | `{"bold": true}` |
| `sz` | 覆盖字号（pt） | `{"sz": 16.4}` |
| `color` | 字色，深色底上的标题用白字 | `{"color": [1,1,1]}` |
| `indent` | 首行缩进（pt），默认自动从原文推断 | `{"indent": 10}` |
| `merge` | 合并被公式/分数切碎的多个块，译文按合并后的大框重排 | `{"merge": ["p7b29","p7b30"]}` |
| `skip_first` | 保留原文行首 N pt 不擦除（彩色编号徽标 ❶❷ 用），译文从该处起排 | `{"skip_first": 7.8}` |
| `top` | 顶对齐（配 `skip_first` 用；默认是底对齐，会把徽标上方空出来） | `{"top": true}` |

`merge` 的目标块也必须出现在同文件里（值写 `""`），否则它们不会被擦除，英文会留在页面上：

```json
{
  "p7b28": "（1）记录 p 的符号位 s……（3）……追加到位数组文件的末尾。",
  "p7b29": "",
  "p7b30": "",
  "@p7b28": {"merge": ["p7b29", "p7b30"]}
}
```

## 数学符号

- 数学字母（𝑝、𝐷、𝑁 等 U+1D400 段）照抄即可，构建时会自动 NFKC 成 ASCII；但**不要**用组合箭头（𝑒⃗）——会被剥掉，直接写 `e`。
- 上下标用可用的字符：`¹²³` 可以，`⁻⁵⁸⁹` 不行（CJK 字体缺字形）。指数统一写 `10^-2`、`2^-24`。
- 区间与集合符号 `(−1, 1)`、`∈`、`∉`、`≥`、`×`、`−`（减号用 U+2212）可以直接用。

## 引用编号与公式编号

- 引用编号原样保留：`[45, 51]`、`[19–21]`。
- 公式编号写成 `式 (1)`、`式 (2)`；公式本身不翻译、不重排（排版引擎不会碰公式块）。
- 章节交叉引用写成 `§6.2`、`（表 3）`、`（图 12）`。

## 行首带编号徽标的段落（❶❷❸❹）

有些论文用小圆形彩色徽标标阶段，徽标里的数字是**正文文本**，因此整行擦除会把数字一起擦掉、
而圆形是矢量图形仍留在原处，出现"空圆 + 中文另起一行"。

处理：保留徽标，让中文从徽标右侧起排并顶对齐。

```json
{
  "p1b36": "**模型注册。**模型由模型开发者或管理员注册进入湖中……",
  "@p1b36": {"skip_first": 7.8, "top": true}
}
```

- `skip_first` 取"徽标右缘到文字起点"的距离（用 `page.get_text('dict')` 看首个 span 的 x0，
  减去该行 bbox 的 x0 即可；示例中徽标 318.3–326.4、文字起于 328.4、行 bbox 起于 320.56 → 7.8）。
- 译文**不要再写数字**（"1 模型注册"❌，"模型注册"✅），数字由徽标里的原文提供。
